Project Synopsis

Guardian AI is an AI-assisted wearable emergency detection and alert system designed as a smart safety locket. The proposed device combines a heart-rate sensor, motion sensor, mini camera, AI processor, GPS/GNSS, cellular communication, vibration motor, rechargeable battery and supplementary solar charging.


During normal operation, the system continuously monitors sensor information using a low-power monitoring process. In this website demonstration, the heart rate first remains within a normal range and then develops a simulated unusual variation. The motion sensor also changes to represent a possible dangerous event.


When the combined sensor conditions cross the predefined demonstration threshold, the AI enters verification mode. The camera changes to recording status, GPS obtains a demonstration location, vibration is activated and the cellular system prepares an emergency notification.


The prototype then displays an emergency message intended for the authorized guardian number 8767531125. In this website version, the message is simulated for the exhibition. Actual SMS transmission would require suitable cellular hardware or a secure backend service.
